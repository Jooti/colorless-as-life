# به بی‌رنگی زندگی

[به بی‌رنگی زندگی](https://jooti.net)؛ یک رمان فانتزی است. کتاب اول از مجموعه فراموشی.

از بخش ریلیزها، می‌توانید فایل epub را دریافت کنید و با reader مورد علاقه خودتان مطالعه کنید. 

یا از سایت اصلی این مجوعه‌ی فانتزی، [jooti.net](https://jooti.net) کتاب را دانلود کنید یا همانجا آنلاین بخوانید.

خواندن مارک‌داون هم کار جذابی است. اگر دوست داشتید، می‌توانید همینجا، از فایلهای md داستان را بخوانید. ترتیب فصلها با شماره‌گذاری اول فایل مشخص شده است.
